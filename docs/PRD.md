# KanPan 看盘小工具 — 产品需求文档（PRD）

版本：v0.1（草案）　日期：2026-10-21

## 1. 产品概述

### 1.1 背景
上班或日常用电脑时想随时看一眼持仓盈亏，但打开券商 App 或行情软件太重、太显眼。需要一个**常驻 Windows 系统托盘、平时几乎不打扰、有异动才提醒**的轻量看盘工具。

### 1.2 产品定位
- 个人自用的 Windows 桌面小工具，只看自己的持仓，不做交易、不做行情分析。
- 核心诉求：**一眼看总盈亏，大波动及时知道**。

### 1.3 目标用户
持有 A 股、场内 ETF、港股，在 Windows 电脑前工作、希望低调看盘的个人投资者。

### 1.4 支持的品种

| 品种 | 计价币种 | 说明 |
| --- | --- | --- |
| A 股股票（沪 / 深 / 北） | 人民币 | |
| 场内 ETF / LOF | 人民币 | 价格精度 3 位小数 |
| 港股（含港股 ETF） | 港币 | 汇总时按实时汇率折算成人民币 |

可转债、美股不在 v1 范围内。

## 3. 功能详述

### F1 导入持仓

**入口**：首次启动自动弹出导入窗口；之后可从主窗口或托盘菜单「编辑持仓」进入。

**导入方式**
1. **粘贴文本**（主推）：每行一条，支持逗号、空格、Tab 分隔。
   ```
   600519,100
   000001 2000
   300750	500	180.5
   ```
   格式：`证券代码, 持仓股数[, 成本价]`
2. **导入文件**：CSV / Excel（.xlsx），列为 代码、股数、成本价(可选)。可下载模板。
3. **手动编辑**：表格中逐行增删改。

**代码识别规则**（用户只填数字，自动判断市场）

| 代码特征 | 市场 |
| --- | --- |
| 6 位：60xxxx、68xxxx、5xxxxx（沪市 ETF / 基金） | 上交所 sh |
| 6 位：00xxxx、30xxxx、1xxxxx（深市 ETF / 基金） | 深交所 sz |
| 6 位：8xxxxx、4xxxxx、92xxxx | 北交所 bj |
| 1–5 位：如 `700`、`00700`、`02800` | 港股 hk（自动补零到 5 位） |
| 也可直接写 `sh600519` / `hk00700` / `0700.HK` 显式指定 | — |

港股成本价按港元填写。注意：Excel 会把 `000001` 这类代码的前导 0 去掉，变成 `1` 后会被识别成港股 00001，预览时名称会对不上；这种情况请写成 `sz000001`，或把 Excel 列设为文本。

**校验**
- 导入后立即拉一次行情，回显股票名称，用户确认后保存；代码无效的行标红提示。
- 股数必须为正整数；同一代码重复出现时合并股数（提示用户）。

### F2 托盘展示整体盈亏

**盈亏口径（重要）**

用户只填「代码 + 股数」时，没有成本价，无法计算持仓累计盈亏，因此定义两种口径：

| 口径 | 公式 | 前提 |
| --- | --- | --- |
| **当日盈亏**（默认） | 当前市值 − 期初持仓昨收市值 + 当日卖出净收入 − 当日买入含费支出 | 需完整登记当天交易和费用；无交易时只需代码和股数 |
| 当日盈亏比例 | 当日盈亏 ÷ 期初持仓昨收市值 | 不含账户现金，期初无持仓时为 0% |
| 持仓盈亏（可选） | Σ (现价 − 成本价) × 股数 | 需填写成本价 |
| 持仓盈亏比例 | 持仓盈亏 ÷ Σ(成本价 × 股数) | 同上 |

**托盘固定显示当日盈亏**。填了成本价的，只在主窗口额外显示持仓盈亏；只统计填了成本价的股票，并在界面注明。

当天清仓的已实现收益仍计入账户当日盈亏；当天交易随持仓保存，重启后恢复，下一交易日不重复计入。尚未登记的交易、费用和分红无法由行情自动推算。

**币种折算**：港股的市值和盈亏按「港币兑人民币」汇率折算成人民币，再与 A 股合计。主窗口明细里，港股的现价、成本价保持港元，市值、当日盈亏、持仓盈亏显示折算后的人民币，这样各列金额能直接相加、排序；状态栏注明当前使用的汇率。
- 汇率来自腾讯（`whHKDCNY`），失败时用新浪（`fx_shkdcny`）。启动时获取一次，港股开市期间每 10 分钟更新，并缓存到 `settings.json`。
- 获取失败时继续使用缓存的汇率，1 分钟后重试；从没成功获取过汇率时，港股行显示现价和涨跌幅，但不计入合计，并在备注里说明。
- 昨收市值和现价市值用同一个汇率，汇率波动不会算进当日盈亏。

**托盘展示形式**
- **托盘图标**：动态绘制，底色随盈亏变化（**红涨绿跌**，符合 A 股习惯；可在设置中反转），图标上显示当日盈亏百分比（如 `1.2`，10% 以上显示整数 `12`），涨跌方向看颜色。
- **鼠标悬停提示**：
  ```
  KanPan  14:32:05
  当日盈亏：+3,256.00 (+1.28%)
  总市值：257,890.00
  ```
- **单击**：打开/隐藏主窗口；**右键菜单**：显示主窗口、编辑持仓、暂停提醒、设置、退出。

> 说明：Windows 11 已不支持在任务栏内嵌入自定义文字，托盘图标也只有 16×16 像素，所以托盘上只能直接看到颜色和百分比，具体金额要鼠标悬停才能看到。

### F3 大涨大跌提醒

**触发条件**：单只持仓股票当日涨跌幅（相对昨收）绝对值 ≥ 5%（阈值可配置）。

**提醒方式**
- Windows 系统通知（Toast）：`【大涨】贵州茅台 600519 +5.32%  现价 1,688.00`
- 托盘图标闪烁，直到用户点开主窗口为止。
- 主窗口中对应行高亮。

**防打扰规则**
- 同一股票、同一方向，每个交易日只在**首次越过**某个档位时提醒。默认档位：5%、7%、9.5%（接近涨跌停）。
- 例：某股票涨到 +5.1% 时提醒一次；在 5%~7% 之间来回波动不再提醒；涨到 +7% 再提醒一次。
- 回落到阈值以下后又重新越过的，默认不重复提醒（可在设置中改为「回落后重新提醒」）。
- 支持「今日暂停提醒」和「勿扰时段」。
- 程序启动时已经超过阈值的股票，汇总成一条通知提醒，不逐条刷屏。

### F4 主窗口（持仓明细）

| 列 | 说明 |
| --- | --- |
| 名称 / 代码 | |
| 现价 | |
| 涨跌幅 | 红绿着色，≥5% 加粗高亮 |
| 持仓股数 | |
| 市值 | 现价 × 股数 |
| 当日盈亏 | |
| 成本价 / 持仓盈亏 | 有成本价时显示 |

- 顶部汇总：总市值、当日盈亏（额/比例）、持仓盈亏（若有）、最后刷新时间、行情状态（交易中 / 午休 / 已收盘 / 网络异常）。
- 支持按任意列排序。
- 关闭按钮 = 最小化到托盘，不退出程序（首次关闭时提示一次）。

### F7 工作模式

- 入口：主窗口右上角「工作模式」开关按钮，托盘右键菜单里也有同名勾选项，两处状态同步。
- 开启后：
  - 不弹系统通知和托盘气泡，托盘图标不闪烁。
  - 托盘图标固定为灰色「K」，鼠标悬停只显示「KanPan（工作模式）」，看不出盈亏。
  - 行情照常刷新，主窗口照常显示数据和异动高亮。
  - 期间触发的异动只写日志，视为已提醒；关闭工作模式后不会补弹。
- 开关状态会保存，重启后保持。

### F8 收盘后自动退出

- 默认开启，工作日北京时间 15:10 自动退出；托盘右键菜单可勾选开关，时间暂时在 `settings.json` 的 `autoExitTime` 里修改。
- 只有在 15:10 之前就已经在运行时才会退出。收盘后再打开（比如晚上复盘），不会被立刻关掉。
- 电脑在 15:10 前休眠、之后才唤醒的，唤醒后退出。
- 正在编辑持仓时不退出，等编辑窗口关闭后再退出。
- 周末不生效。
- 每 30 秒检查一次，实际退出时间最多比设定时间晚 30 秒。
- 持有港股时，退出时间自动推迟到 16:20（港股收市竞价 16:10 结束后 10 分钟），托盘菜单上显示实际的退出时间。设置的时间本来就晚于 16:20 的，按设置的来。

### F9 记一笔交易

- 入口：主窗口「记一笔交易…」按钮（选中某行时自动带出这只股票）、双击持仓行、托盘右键菜单「记一笔交易…」。
- 填写：方向（买入 / 建仓、卖出）、股票（下拉选已有持仓，或直接输入新代码建仓）、成交价、数量、手续费（可不填）。
  - 「用现价」一键填入最新价；卖出时「全部卖出」一键填入全部持仓股数。
  - 输入新代码时会查一次行情，显示名称和现价；查不到的代码不能保存，网络失败时仍可保存。
- 窗口下方实时预览交易前后的股数和成本价，保存后立即写入持仓并刷新行情。
- 计算规则：
  - 买入：新成本 =（原股数 × 原成本 + 数量 × 成交价 + 手续费）÷ 新股数。
  - 卖出，默认「摊薄成本」：新成本 =（原股数 × 原成本 −（数量 × 成交价 − 手续费））÷ 剩余股数。赚钱卖出后成本价下降，收回全部本金后可能为 0 或负数，会给出提示。
  - 卖出，可选「加权平均」：只减股数，成本价不变。选择会被记住。
  - 全部卖出 = 清仓，从持仓中移除。卖出数量超过持仓、卖出未持有的股票都不能保存。
  - 原持仓没填成本价的，只更新股数，并提示去「编辑持仓」补填。
- 成本价保留 4 位小数。不保存交易流水，只记日志。

### F6 设置（P1）

- 刷新间隔：3s / 5s（默认）/ 10s / 30s
- 提醒阈值：默认 5%，档位可编辑
- 颜色习惯：红涨绿跌（默认）/ 绿涨红跌
- 开机自启动
- 老板键：全局快捷键（默认 `Ctrl+Alt+K`），一键隐藏所有窗口
- 隐私模式：只显示百分比，不显示金额

## 4. 行情时段行为

A 股和港股的交易时段不同，按市场分别判断（均为北京时间）：

| 阶段 | A 股 | 港股 | 行为 |
| --- | --- | --- | --- |
| 开盘前竞价 | 09:15–09:30 | 09:00–09:30 | 按设定间隔刷新，**不触发提醒** |
| 连续交易 | 09:30–11:30、13:00–15:00 | 09:30–12:00、13:00–16:00 | 按设定间隔刷新，正常提醒 |
| 午休 | 11:30–13:00 | 12:00–13:00 | 降频为 60 秒一次 |
| 收市竞价 | — | 16:00–16:10 | 按设定间隔刷新，不触发提醒 |
| 收盘后 / 非交易日 | | | 停止轮询，展示收盘数据 |

- 只要有一个市场还在交易，就继续轮询，但只请求当前在交易的那个市场的股票。
- 非交易日（节假日）判定：按市场分别看行情返回的时间是否为当天，不维护节假日表。两地节假日不同，比如香港放假、A 股照常开盘的日子，港股就显示上一交易日的收盘数据，当日盈亏按 0 计。

## 5. 非功能需求

- **轻量**：常驻内存 < 80MB，空闲时 CPU ≈ 0。
- **稳定**：网络断开时保留最后一次数据，并标记「数据过期」；网络恢复后自动重连。
- **隐私**：持仓数据只存在本机，不上传任何服务器（只向行情接口请求证券代码）。
- **兼容**：Windows 10 1809+ / Windows 11，支持高 DPI。
- **分发**：单个 exe 或绿色免安装压缩包。

## 6. 不做的事情（v1 范围外）

- 交易下单、券商账户对接、自动同步持仓
- K 线图、技术指标、资讯新闻
- 多账户、云同步
- 交易流水、持仓变动历史、收益曲线（可列入后续版本）
